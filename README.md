# 🎯 코디세이 올인원 퀴즈

## 프로젝트 개요
코디세이 올인원 교육 과정에 관한 내용을 퀴즈로 풀어보는 콘솔 기반 퀴즈 게임입니다.

## 퀴즈 주제 선정 이유
같은 교육을 받고 있는 동료 교육생들에게 발표하는 자리인 만큼,
모두가 공감할 수 있는 주제인 코디세이 올인원 과정을 선택했습니다.

## 실행 방법
```bash
python main.py
```
> Python 3.10 이상 필요 / 외부 라이브러리 설치 불필요

## 기능 목록
- 퀴즈 풀기: 등록된 퀴즈를 순서대로 풀고 점수 확인
- 퀴즈 추가: 새로운 퀴즈 직접 등록
- 퀴즈 목록: 등록된 전체 퀴즈 확인
- 점수 확인: 최고 점수 조회

## 파일 구조
```
E1-2/
├── main.py       # 메인 프로그램 (Quiz, QuizGame 클래스)
├── state.json    # 퀴즈 데이터 및 최고 점수 저장 파일 (자동 생성)
├── .gitignore    # Git 제외 파일 목록
└── README.md     # 프로젝트 설명
```

## 데이터 파일 설명 (state.json)
- **경로**: 프로젝트 루트 (`state.json`)
- **역할**: 퀴즈 목록과 최고 점수를 프로그램 종료 후에도 유지
- **인코딩**: UTF-8
- **스키마**:
```json
{
    "quizzes": [
        {
            "question": "문제 텍스트",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 1
        }
    ],
    "best_score": 0
}
```
