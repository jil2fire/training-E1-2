# 🎯 코디세이 올인원 퀴즈

## 프로젝트 개요
코디세이 올인원 교육 과정에 관한 내용을 퀴즈로 풀어보는 콘솔 기반 퀴즈 게임입니다.  
퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 확인, 최고 점수 조회 기능을 제공하며,  
프로그램을 종료해도 추가한 퀴즈와 최고 점수가 유지됩니다.

---

## 퀴즈 주제 선정 이유
같은 코디세이 올인원 교육을 받고 있는 동료 교육생들에게 발표하는 자리인 만큼,  
모두가 직접 경험한 내용으로 공감대를 형성할 수 있는 주제를 선택했습니다.

---

## 실행 방법
```bash
python main.py
```
> - Python 3.10 이상 필요
> - 외부 라이브러리 설치 불필요 (표준 라이브러리만 사용)
> - 첫 실행 시 `state.json`이 자동으로 생성됩니다

---

## 기능 목록

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 퀴즈 풀기 | 등록된 퀴즈를 순서대로 풀고 최종 점수 확인 |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호를 입력해 새 퀴즈 등록 |
| 3 | 퀴즈 목록 | 현재 등록된 전체 퀴즈 목록 조회 |
| 4 | 점수 확인 | 지금까지의 최고 점수 조회 |
| 5 | 종료 | 데이터 저장 후 프로그램 종료 |

## 데이터 파일 설명 (state.json)

- **경로**: 프로젝트 루트 (`./state.json`)
- **역할**: 퀴즈 목록과 최고 점수를 프로그램 종료 후에도 유지
- **생성 시점**: 프로그램 첫 실행 시 자동 생성
- **인코딩**: UTF-8

### 스키마
```json
{
    "quizzes": [
        {
            "question": "문제 텍스트 (str)",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 1
        }
    ],
    "best_score": 0
}
```

| 필드 | 타입 | 설명 |
|------|------|------|
| `quizzes` | list | 퀴즈 객체 목록 |
| `quizzes[].question` | str | 문제 텍스트 |
| `quizzes[].choices` | list[str] | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `best_score` | int | 최고 점수 (백분율, 0~100) |
